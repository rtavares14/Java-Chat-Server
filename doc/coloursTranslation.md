# Color Meaning Guide

This document explains the meaning of various colors used in the application:

- **GREEN**: User login success
- **RED**: Error messages
- **BLUE**: Other user login
- **CYAN**: User list
- **ORANGE**: Global message
- **WHITE**: Private message
- **YELLOW**: User left
- **PURPLE**: Server logs
- **OLIVE**: Rock-Paper-Scissors (RPS)
- **TEAL**: File transfer activities
