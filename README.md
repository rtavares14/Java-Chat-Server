This project is a command-line chat system developed in Java that facilitates real-time communication between multiple users through a centralized server. The server functions as a hub, relaying messages and commands among the various connected clients by strictly adhering to the guidelines specified in the doc/protocol.md document.</br>

Key features include:</br>
- User Authentication: Log in to the network.</br>
- Public Messaging: Broadcast messages to all connected users.</br>
- User List: Retrieve a list of currently active users.</br>
- Private Messaging: Exchange direct messages between individual users.</br>
- Games: Engage in a game of rock-paper-scissors.</br>
- File Transfer: Send files to other clients.</br>

To operate the chat application, launch the server by running Server.java, and then initiate one or more client sessions using Client.java.
